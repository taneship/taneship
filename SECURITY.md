# Security Policy

## Reporting a vulnerability

Report a vulnerability privately, never in a public issue, discussion or pull request. Use GitHub's private vulnerability reporting: the repository's Security tab, then [Report a vulnerability](https://github.com/taneship/taneship/security/advisories/new).

Describe the vulnerability, the version it affects and the steps that reproduce it. The report stays private while it is fixed. The fix ships in a new release, whose notes credit you unless you prefer otherwise.

## Supported versions

Security fixes land in a new release of the latest version.

A project created from Taneship owns its code, so no update reaches it on its own: apply the fix by hand, following the release notes and the diff they link to.
